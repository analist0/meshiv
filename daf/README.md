# 📝 דף: מחברת בלוקים בעברית עם AI מכל מודל

אפליקציית פתקים ומסמכים בסגנון "בלוקים". כולה בעברית, מיושרת לימין (RTL),
ועם עוזר AI שאפשר לחבר **לכל מודל**, כולל מודלים **חינמיים ומקומיים**.

- בלי תלויות (Node.js 20+ בלבד), בלי חשבון ובלי ענן.
- כל הדפים נשמרים מקומית בדפדפן (localStorage), עם ייצוא/ייבוא גיבוי JSON.

## הפעלה

```bash
cd daf
npm start
# פתח בדפדפן: http://localhost:3210
```

## חיבור למודל (⚙️ הגדרות מודל AI)

השרת המקומי (`server.js`) מעביר את הבקשות לכל API **תואם OpenAI** (`/chat/completions`) או ל-**Anthropic**.
יש הגדרות מוכנות מראש:

| ספק | עלות | הערה |
|---|---|---|
| **Ollama** | ✅ חינם, מקומי | `ollama pull llama3.2`. בלי מפתח ובלי אינטרנט |
| **LM Studio** | ✅ חינם, מקומי | הפעל Local Server |
| **OpenRouter** | ✅ מודלים עם `:free` | מפתח חינמי |
| **Groq** | ✅ שכבה חינמית | מהיר מאוד |
| **Google Gemini** | ✅ שכבה חינמית | מפתח מ-AI Studio |
| **Hugging Face** | ✅ שכבה חינמית | טוקן HF |
| Mistral, xAI, OpenAI, Claude | בתשלום / ניסיון | |
| מותאם אישית | — | vLLM, llama.cpp, DeepSeek, Together וכל שרת תואם OpenAI |

שמות המודלים בהגדרות המוכנות הם ברירת מחדל בלבד. ספקים מחליפים מודלים חינמיים
מדי פעם, אז אם מודל לא עובד, החלף את השם לפי הרשימה באתר הספק ולחץ "🔌 בדוק חיבור".

### מפתח בצד השרת (אופציונלי)

אפשר לא לשמור את המפתח בדפדפן, אלא להגדיר אותו בהפעלה:

```bash
AI_KIND=openai AI_BASE_URL=https://api.groq.com/openai/v1 \
AI_MODEL=llama-3.3-70b-versatile AI_API_KEY=gsk_... npm start
```

שדה שמשאירים ריק בהגדרות משתמש בערך מהשרת.

## פרסום ב-Vercel

התיקייה מוכנה ל-Vercel: `public/` מוגש כאתר סטטי, ו-`api/ai.js` ו-`api/config.js` רצים כפונקציות שרת.
בפרויקט Vercel, הגדר את **Root Directory** ל-`daf`.

בגרסה המפורסמת:
- אפשר להתחבר רק לספקי ענן ב-`https` (OpenRouter, Groq, Gemini וכו'). מודלים מקומיים (Ollama ו-LM Studio) עובדים רק בהרצה מקומית.
- **אל תגדיר `AI_API_KEY` בפרויקט ציבורי.** כל מי שיש לו את הכתובת יוכל להשתמש במפתח שלך. כל משתמש מזין את המפתח שלו בהגדרות.
- הדפים נשמרים בדפדפן של כל משתמש, לא בשרת.

## אבטחה ופרטיות

- השרת מאזין רק ל-`127.0.0.1` (לשינוי: `HOST=0.0.0.0`, אבל אז כל מי שברשת יכול להשתמש במפתח שלך).
- מפתח שהוזן בהגדרות נשמר ב-localStorage של הדפדפן הזה בלבד.
- תוכן הדף נשלח לספק ה-AI רק כשלוחצים על פעולת AI. עם Ollama או LM Studio התוכן לא יוצא מהמחשב.
