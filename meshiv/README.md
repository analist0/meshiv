# 💬 משיב: מענה אוטומטי חכם לוואטסאפ

בוט מענה אוטומטי בעברית ל-WhatsApp, מבוסס [open-wa](https://github.com/open-wa/wa-automate-nodejs) v5.
יש לו לוח בקרה מלא בעברית מימין לשמאל, סימולטור לבדיקה בלי טלפון, ומענה AI שעובד עם כל מודל, כולל מודלים חינמיים ומקומיים.

> ⚠️ **חשוב לדעת:** open-wa מתחבר ל-WhatsApp Web בדרך **לא רשמית**. WhatsApp עלולה להגביל או לחסום מספרים שמשתמשים באוטומציה.
> מומלץ להשתמש במספר נפרד, לשמור על קצב סביר, ולא לשלוח הודעות שלא ביקשו לקבל.

## מה יש

| תחום | יכולות |
|---|---|
| ⚡ **חוקים** | 7 סוגי התאמה: מכיל, מדויק, מתחיל ב-, מסתיים ב-, **דומה** (סובל שגיאות כתיב בעברית, ניקוד ואותיות סופיות), ביטוי רגולרי, כל הודעה. כמה מילות מפתח וכמה תשובות לכל חוק (אקראית, בסבב או כולן). פרטי/קבוצות, ימים ושעות, השהיה לכל איש קשר, סדר עדיפויות, "המשך לחוק הבא", העברה ל-AI |
| 📋 **תפריט** | תפריט ממוספר עם תתי-תפריטים, "0" לחזרה, תפוגה, ופריט "דבר עם נציג" שמשתיק את הבוט |
| 🤖 **AI** | כל מודל: Ollama ו-LM Studio (מקומי וחינמי), OpenRouter `:free`, Groq, Gemini, Hugging Face, OpenAI ו-Claude. אישיות, מאגר ידע על העסק וזיכרון שיחה לכל לקוח. כגיבוי כשאין חוק, או תמיד |
| 👋 **ברוך הבא** | הודעה בפנייה ראשונה, ואפשר לחזור עליה אחרי X ימים |
| 🕘 **שעות פעילות** | הודעת "לא זמין" מחוץ לשעות, כולל חלונות שחוצים חצות ואזור זמן |
| 🧍 **התנהגות אנושית** | השהיה אקראית, ציטוט ההודעה, **השתקה אוטומטית כשאתה עונה ידנית**, ופקודות `!עצור` / `!המשך` מהטלפון |
| 🎯 **סינון** | פרטי/קבוצות, רשימה שחורה, "רק למספרים האלה", מגבלת תשובות יומית לאיש קשר |
| 🔤 **משתנים** | `{name}` `{phone}` `{greeting}` (בוקר טוב/ערב טוב…) `{day}` `{date}` `{time}` `{message}` |
| 📊 **לוח בקרה** | חיבור עם QR, סטטיסטיקה, חוקים מובילים, יומן חי, אנשי קשר עם השתקה והפעלה, ייצוא וייבוא הגדרות |
| 🧪 **סימולטור** | צ'אט שמראה בדיוק מה הבוט יענה, ולמה, בלי WhatsApp |

## התקנה

דרישות: Node.js 20 ומעלה, Google Chrome, והכלי `zstd`, ש-open-wa v5 צריך:

```bash
# macOS
brew install zstd
# Ubuntu / Debian
sudo apt install zstd
# Windows: להוריד מ-https://github.com/facebook/zstd/releases ולהוסיף ל-PATH
```

```bash
cd meshiv
npm install
npm start
# פתח: http://localhost:3300 → סרוק את ה-QR (WhatsApp → מכשירים מקושרים → קישור מכשיר)
```

רק לבדוק בלי WhatsApp:

```bash
npm run sim    # לוח בקרה וסימולטור, בלי חיבור
npm test       # בדיקות המנוע
```

## משתני סביבה

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | `3300` | פורט לוח הבקרה |
| `HOST` | `127.0.0.1` | רק המחשב שלך. אם משנים ל-`0.0.0.0`, הגדר גם סיסמה |
| `DASHBOARD_PASSWORD` | — | סיסמה ללוח הבקרה (Basic Auth) |
| `CHROME_PATH` | — | נתיב ל-Chrome/Chromium אם הוא לא מותקן במקום הרגיל |
| `MESHIV_DATA` | `./data` | הגדרות, מצב והתחברות (session) |
| `AI_API_KEY` | — | מפתח AI מצד השרת, במקום לשמור אותו בהגדרות |
| `OPENWA_LICENSE_KEY` | — | רישיון open-wa לפיצ'רים בתשלום (לא נדרש למענה טקסט) |

## איפה להריץ 24/7

הבוט צריך דפדפן שרץ ברקע כל הזמן, ולכן **הוא לא מתאים ל-Vercel** או לפונקציות serverless.
מריצים אותו על מחשב ביתי, על Raspberry Pi או על שרת VPS.

👉 **[מדריך: הרצה על המחשב בבית עם כתובת משלך (Cloudflare Tunnel)](HOME-SERVER.md)**

**שרת Docker** (למשל Hugging Face Spaces, או כל VPS): בתיקייה הראשית של המאגר יש `Dockerfile`.
חובה להגדיר סוד `DASHBOARD_PASSWORD`. בלעדיו השרת מסרב לעלות, כי לוח הבקרה פתוח לרשת.

```bash
docker build -t meshiv .
docker run -d -p 7860:7860 -e DASHBOARD_PASSWORD=סיסמה-חזקה -v meshiv-data:/home/node/data meshiv
```

## מבנה

```
│   └── server.js     ← API + לוח בקרה + אירועים חיים

```

## רישיון open-wa

open-wa מופץ ברישיון H-DNH (Hippocratic + Do Not Harm). השימוש בו כפוף לתנאים שלו ולתנאי השימוש של WhatsApp.
