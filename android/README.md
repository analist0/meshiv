# 📱 משיב לאנדרואיד

אפליקציית אנדרואיד מלאה של משיב. **עונה להודעות WhatsApp ישירות מהטלפון**, בלי מחשב, בלי שרת ובלי סריקת QR.

## איך זה עובד

משיב מקבל הרשאה לקרוא התראות. כשמגיעה התראת WhatsApp, הוא מחליט מה לענות (חוקים, תפריט, שעות פעילות, AI)
ועונה **מתוך ההתראה**, כמו כשלוחצים "תשובה" בהתראה. זו אותה שיטה שבה עובדות אפליקציות מענה אוטומטי בחנות.

- **אותו מנוע ואותו לוח בקרה** כמו בגרסת השרת. לוח הבקרה (`meshiv/public`) וברירות המחדל (`meshiv/src/default-config.json`) נטענים מאותם קבצים, והמנוע (`Engine.kt`) הוא תרגום של `engine.js` שעובר את אותן בדיקות.
- **הכל נשאר בטלפון.** אין שרת של משיב. האינטרנט משמש רק לתשובות AI, אם הפעלת אותן.
- WhatsApp ו-WhatsApp Business נתמכים.

### מגבלות (חשוב לדעת)

- הבוט עונה רק להודעות **שמגיעות כהתראה**. אם ההתראות של צ'אט מושתקות, או שהצ'אט פתוח על המסך, אין התראה ואין תשובה.
- אין מספר טלפון בהתראות, רק שם. לכן ברשימות "לא לענות" / "רק ל-" כותבים **שם איש קשר** כפי שהוא שמור בטלפון.
- "מענה ידני משתיק את הבוט" עובד כשעונים מתוך ההתראה. אם עונים מתוך אפליקציית WhatsApp, משיב לא רואה את התשובה.
- ציטוט הודעה וחיבור QR קיימים רק בגרסת השרת, ומוסתרים באפליקציה.

## התקנה

1. העבר את `meshiv-1.0.0.apk` לטלפון ופתח אותו. אנדרואיד יבקש לאשר "התקנה ממקור לא ידוע". אשר.
2. פתח את משיב ← **הפעל הרשאת התראות** ← הפעל את "משיב".
3. אם ההפעלה חסומה ("הגדרה מוגבלת", באנדרואיד 13 ומעלה): הגדרות ← אפליקציות ← משיב ← ⋮ ← **אפשר הגדרות מוגבלות**, ואז שוב שלב 2.
4. לחץ **לא להגביל ברקע**, כדי שחיסכון הסוללה לא יעצור את משיב.
5. הגדר חוקים, ובדוק בלשונית 🧪 סימולטור.

## בנייה מהקוד

דרישות: JDK 17 ומעלה, ו-Android SDK (platform 35, build-tools 35).

```bash
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew testDebugUnitTest   # בדיקות המנוע
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

גרסה חתומה (release): צור `keystore.properties` (לא נשמר ב-Git):

```properties
storeFile=/path/to/meshiv-release.jks
storePassword=...
keyAlias=meshiv
keyPassword=...
```

ואז `./gradlew assembleRelease`. **שמור את קובץ החתימה.** עדכונים חייבים להיחתם באותו מפתח, אחרת צריך להסיר את האפליקציה ולהתקין מחדש.

## מבנה

```
android/app/src/main/java/com/elyasharlabs/meshiv/
├── Engine.kt                 ← מנוע ההחלטות (תרגום של engine.js)
├── ReplyListenerService.kt   ← קורא התראות WhatsApp ועונה מתוכן
├── Api.kt                    ← אותם נתיבי /api כמו השרת, ללוח הבקרה
├── MainActivity.kt           ← לוח הבקרה ב-WebView + גשר JS
├── Meshiv.kt                 ← הגדרות, מצב ויומן (קבצי JSON בטלפון)
└── Ai.kt                     ← כל ספק AI
```
